02

點樣用？

  1. 01

    發佈或搜尋行程

    揀司機／乘客模式，輸入出發地、目的地同時間窗。

  2. 02

    尋找配對

    瀏覽同路行程，或等其他用戶 join 你嘅行程。

  3. 03

    App 內傾好細節

    唔使交換電話，直接喺內置聊天室傾集合點、上落車位、車費分擔方式。

  4. 04

    出發

    一齊上車，分享車費，返工都可以變得更舒服。

03

熱門返工路線

ROUTE →

將軍澳 → 中環/金鐘

返工核心線；適合用「時間窗」＋「觀塘/九龍灣中途站」。

ROUTE →

將軍澳 → 鰂魚涌/太古

港島東返工；可寫明「是否接受跨海隧道/路費分擔」。

ROUTE →

元朗/天水圍 → 九龍東

新界西返工；建議用固定星期一至五 post 建立長期圈。

ROUTE →

沙田 → 金鐘/中環

新界東返工；可設 1–2 個上車點減少兜路。

ROUTE →

荃灣 → 中環/金鐘

西區返工；適合朝早固定時間窗配對。

ROUTE →

東九龍 → 灣仔/銅鑼灣

跨海返工；事前講清楚「隧道費點分」最重要。

熱門使用指南

  • 夾 Taxi / Uber 分擔

    同路一齊搭，車費平啲，集合點同分帳先講清楚。

    →

  • 去機場夾車

    行李、上車點、出發時間：三樣寫清楚就容易夾。

    →

  • 返大陸拼車/順風

    跨境行程更要先約好證件/集合地標/分擔方式。

    →

  • 週末出去玩

    郊遊、行山、去沙灘，一齊夾車出發更好玩。

    →

App介面預覽

主畫面：快速進入「司機/乘客」模式，同時睇到熱門返工路線入口。

建立行程：用「時間窗」寫法，並可加中途站提升配對成功率。

內置聊天室：唔使交換電話號碼，直接傾集合點同分擔安排。

行程列表：瀏覽同路行程，配合篩選更快搵到適合嘅返工/出行。
